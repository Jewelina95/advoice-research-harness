Evidence-governed cognitive screening from speech

One auditable path from recording to cognitive-state evidence.

ADvoice routes each speech task through modality-specific processing, converts measurements into typed evidence, aggregates them into cognitive StateCards, and constrains a single diagnostic Agent to cite the evidence it uses.

Four public synthetic channels No participant data in this repository Research use only
This page runs Audio and transcript evidence extraction

It does not load clinical weights or emit a disease probability. Full cohort prediction and the configured GPT Agent require licensed datasets and the frozen research command.

System architecture

Task-aware processing before prediction

The public demo exposes the same evidence contract used by the research harness. The trained pipeline adds out-of-fold prediction, a validation-frozen correction policy, and locked report rendering.

Learned components

Prediction and fusion weights

Five-fold subject-level training fits the statistical prior and selects low-capacity fusion candidates on development data.

Agent contract

Evidence scoring, not free diagnosis

The configured Agent reads a blinded evidence workspace and returns ordinal class evidence plus valid source IDs.
