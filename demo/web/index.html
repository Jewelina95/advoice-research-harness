System method

From a heterogeneous recording to a locked report

The same evidence contract is used across interviews, picture descriptions, structured cognitive tasks, and natural speech. Task routing determines which evidence is observable before any prediction is made.

Evidence contract

Measurements remain inspectable

Every finding retains its observed value, reference scope, direction, reliability, confounds, task, and source segment.

Cognitive-state model

Related metrics do not vote twice

Correlated measurements are consolidated into task-aware cognitive states before learned fusion.

Constrained Agent

Evidence review precedes communication

The Agent cites registered evidence and counter-evidence. Invalid or unsupported updates are rejected before reporting.

Reproducibility

Run the demonstration and inspect the implementation

The browser demonstration runs from packaged synthetic cases. A licensed dataset is mounted locally for cohort execution; raw participant files are never committed.

Start the browser demo 
git clone https://github.com/Jewelina95/advoice-research-harness.git
cd advoice-research-harness
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
make demo

Open http://127.0.0.1:8765, select a recording, and press Run selected recording.

Run the ADReSS cohort 
make validate DATASET=ADReSS_2020
make full DATASET=ADReSS_2020
make evaluate DATASET=ADReSS_2020
make report DATASET=ADReSS_2020

The dataset path and exclusions are declared in configs/datasets/ADReSS_2020.yaml.
