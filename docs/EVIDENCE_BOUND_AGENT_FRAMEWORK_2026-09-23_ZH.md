# ADvoice 证据约束诊断框架（2026-09-23）

## 研究定义

本系统不是让大模型自由生成一段诊断解释，而是把语音片段、量化指标、认知状态、Agent 操作、概率变化和医生报告连接为一条可验证、可干预、可回放的决策来源链：

`AudioSegment -> MetricEvidence -> StateCard(v0) -> AgentEvidence/AgentOperation -> StateCard(v1) -> JointFusion -> ReportClaim`

论文应使用“基于证据干预验证、保留数据来源的认知状态决策链”，不应声称回放了模型内部思维过程。

## 当前六步执行链

1. **任务与角色路由**：按图片描述、临床访谈、结构化任务、公开讲话以及语言和说话者角色确定可观察指标；任务不支持的指标保持 unavailable，不按零值处理。
2. **MetricEvidence**：每个指标保存原始值、方向、参考信息、可靠度分量、混杂、任务、片段来源以及推断和报告权限。
3. **StateCard**：同一认知状态内先按相关家族限额，再进行稳健聚合；保留共享状态和训练折内可识别的任务残差，避免在融合前抹平任务差异。
4. **监督模块**：只在训练折拟合任务和语言条件化的统计专家，输出冻结概率及贡献；它提供可校准的预测锚点，但不是最终解释。
5. **证据约束 Agent**：Agent 可以审查证据、降权、失效或要求复测，并输出类别证据强度。每个非中性最高/最低类别判断必须引用合法的 `class -> state -> MetricEvidence` 路径。没有合法引用时，Agent 对概率的影响严格为零。
6. **分层联合融合与报告锁**：先估计 HC 对认知受损，再在受损条件下区分 MCI 与 AD。MCI/AD 分期证据不得改变 HC 质量；报告结论只能引用仍可用且具有报告权限的证据。

## 本轮修复

- 修复三分类融合：分期证据只重分配 MCI/AD，不再错误改变 HC 概率。
- 修复评估计算：`log_loss` 显式使用声明的 `HC/MCI/AD` 类别顺序，避免 sklearn 字母排序造成假性劣化。
- 新增 `LikelihoodEvidenceCitation`：Agent 分数必须绑定类别、状态、支持/反驳关系和 MetricEvidence ID。
- 新增保守证据权重：由合法引用的可靠度、观察混杂和独立状态数决定。
- 修改权限门控：监督模型不确定性只决定是否允许复核，不再连续放大 Agent 权重。
- 保持旧缓存安全：没有新证据引用字段的旧 Agent 结果不获得预测权限。
- 补齐新生成参考集的样本数元数据；融合审计显式区分 `inactive_unvalidated_strength`、`blocked_no_validated_evidence`、`eligible_but_not_applied` 与 `active`，避免把“运行了 Agent”误写成“Agent 参与了预测”。
- 封闭非零权重绕过路径：研究运行器必须同时接收并核验校准 artifact 内容、内容哈希、验证状态、部署上下文以及 state/screening/staging 三类权重；仅提供哈希、上下文不匹配或命令行手工权重都会在调用 Agent 前失败。
- 部署上下文现在绑定数据清单、证据/片段/状态表、监督模型、预测快照、Module A、状态配置、相关家族配置和 Agent 运行身份；旧模型或旧数据生成的校准 artifact 不能静默复用。
- 非零权限还必须出现在仓库控制的校准注册表中；注册项绑定开发集被试清单、OOF 预测、预注册验收指标、训练代码/配置与“未使用测试标签”声明。当前注册表为空，因此任何未完成正式开发校准的 Agent/state 权限都会失败关闭。
- 校准 artifact 同时绑定完整融合配置；温度、状态改变量上限、冲突门控或任一阈值变化都会改变部署上下文并使旧校准失效。
- MCI/AD 分期采用独立证据强度；只有同时存在对首选阶段的支持和对另一阶段的反证时才可启动，普通“认知受损”证据不能获得分期权限。
- 历史多数据集 pilot 需要显式传入 `--allow-unvalidated-pilot`，输出同时标记 `publication_eligible=false` 和 `non_deployable_unvalidated_historical_pilot`，防止硬编码权重结果混入正式评估。

## 已验证结果

- 全仓库隔离测试：`868 passed, 3 skipped`；跳过项沿用既有环境依赖，不涉及本轮融合变更。
- 四个真实通道的去标签数据准备 smoke test 均通过，且没有外部模型调用：
  - ADReSS 2020：英文图片描述；
  - DementiaNet PublicFigures：英文公开讲话；
  - NCMMSC2021_AD：中文长时结构化图片描述，未使用 6 秒短片；
  - IAEAV：西班牙语结构化临床访谈。
- 每个通道抽取 3 例，真实执行训练折内 Module A 拟合、MetricEvidence/StateCard 构建、任务路由、转录覆盖检查和三重哈希绑定。
- smoke 结果保存在 `.local/evidence-bound-smoke/*.json`。

## 真实小模型盲审的停止结论

- 初次四通道 Luna 请求均未完整满足新的类别—状态—证据引用契约，运行时按设计拒绝，概率没有变化。
- 收紧提示后，ADReSS 个案 `S011` 通过结构校验并获得 `0.7363` 的证据质量分；但该病例真实标签为 HC，冻结模型正确预测 HC，未校准的 Agent 却把结果改成 AD。
- 这说明“引用合法”只能证明来源可核查，不能证明医学判断正确。`direction` 表示指标对相应认知状态负担的方向，不是从指标直接到 HC/MCI/AD 的疾病标签规则。
- 本轮因此停止更多 API 与全量测试。默认 `agent_strength=0` 保留原监督结果；Agent 仍可审查、撤销和触发证据重放，但只有在独立开发集完成伤害约束校准后才能获得预测权限。
- 旧的缓存 artifact 仍可能显示 `reference.sample_size=0`，因为它们是在修复前生成的。代码已修复新 artifact 的参考样本数记录；不能在读取旧 artifact 时猜测或伪造该数值。

## 尚未成立的结论

- 四通道 smoke test 证明输入和证据链可以运行，不证明 Agent 提升准确率。
- 单例 Luna 盲态测试只检查新 schema 是否可执行，不用于估计 AUROC、F1 或准确率。
- 尚未完成同一编码器、同一切分、完整 PREPARE 官方测试集上的配对比较，因此目前不能声称超过 SpeechCARE。
- IAEAV 的训练矩阵出现全空特征列警告。虽然准备链通过，但正式训练前必须删除该折全空列或在特征白名单阶段失败关闭。
- 当前证据质量分仍不能证明“指标到疾病类别”的医学方向正确。代码已阻止跨 StateCard 重复使用同一 metric ID 增加权限，但尚未识别不同名称、同一生理来源的相关指标家族。默认 Agent 预测权限为零，使该缺口目前不会改变标签；正式开放权限前必须加入任务/语言条件化的表型关系注册表和相关来源家族治理。

## 正式进入全量实验的发布门槛

1. 固定开发集上校准 `state_strength`、`agent_strength` 和 `staging_strength`，测试集不得调参。
   校准目标必须同时约束 `harm <= help`、类别分层非劣效和 log-loss/Brier 不恶化；不能只最大化准确率。
2. 完成删除关键证据、重复同源证据、非法 ID、QC 冒充疾病证据、来源撤销和离线方向更新六类干预测试。
3. 报告 Agent 的 corrected、harmed、net correction、覆盖率和校准误差，不能只报告准确率。
4. PREPARE 必须使用与 SpeechCARE 相同的官方测试 cohort、类别定义和重复种子协议；未满足时只报告内部结果，不做胜负结论。
5. 全量运行前先用每通道 2–4 例真实 API 进行 schema 和 token 预算检查；单例超时、非法引用或无证据大幅跳变即停止。
6. 证据权重必须按独立来源家族计算，而不是按 StateCard 数量累计；同一指标映射到多个状态不能重复增加 Agent 权限。
