# Evidence Governance：研究计划与第一轮底层结果

日期：2026-09-17。基线代码：`c194ec0`。研究分支：`research/evidence-governance-overlap`。

本轮完成的是只读结构分析、训练分区统计和研究工具验证，不是新模型训练、临床验证或准确率提升。没有修改正式预测代码、删除历史指标、使用测试标签选特征或批量调用在线 Agent。

## 1. 研究命题

需要回答的不是“179 个指标能否完全正交”，而是：这些指标分别测量什么；何时提供新信息，何时只是重复表达；证据纠正是否能传到实际预测与报告；精简后能否保留必要的预测和审查能力。

临床状态之间相关是合理现象。停顿、连续性和输出效率可能来自同一行为；问题不是必须消除这种相关，而是不能将同源观测当成相互独立的多份证据。QC 即使不提高准确率，也可能对拒判、质量审查与权限控制有价值，不能仅按预测贡献删除。

建议把核心研究定位为“依赖感知、可修正、可核验的认知筛查证据体系”。其中来源和运算约束可以做确定性检验；从语音状态到疾病标签的有效性仍需要统计和临床验证。

## 2. 179 项到底是什么

| 层级 | 本轮实测 | 含义 |
| --- | ---: | --- |
| 历史候选字典 | 180 行、179 个不同名称 | 不是当前全部已启用或相互独立的输入 |
| 历史行中有显式列引用 | 147 行 | 保留原来的对应信息，不猜测新映射 |
| 被引用的不同历史列名 | 134 | 不能直接当成当前运行列名 |
| 被多行引用的历史列名 | 14 | 同源复用复核候选，不等于已确认 14 项可以删除 |
| 当前运行基础定义 | 37 | 包含 QC 与辅助指标，不含全部嵌入维数、MFCC 或任务展开列 |
| 当前状态配置 | 14 | 包括未启用或在特定病例不可观察的状态 |

仅有 1 行历史名称与当前运行 ID 完全同名。这反映两个登记体系命名不同，绝不表示其他 178 项全部丢失。建立完整版本映射仍是待完成的工作。

历史字典里，`MeanUnvoicedSegmentLength` 与 `egemaps_MeanUnvoicedSegmentLength` 指向同一个历史列；更值得检查的是 `embedding_coherence`、`semantic_coherence_tfidf`、`task_relevance`、`topic_drift` 四个名称均引用 `s09_coherence_jaccard`。它们的概念名称不同，旧映射却复用了同一代理量。不能据此宣传四种独立语义能力。当前 S09 已是空指标的规划状态，这不是指它现在仍作为四项投入模型。

## 3. 已运行的数据与统计边界

四份现有特征表分别运行，未合并数据集。仅分析明确标为 `train` 的 2,032 条记录；506 条非训练记录未进入统计。没有把多任务列展开成额外受试者。

| 特征来源 | 训练记录 | 语言 | 分析限制 |
| --- | ---: | --- | --- |
| PREPARE | 1,622 | 英语 1,308；西班牙语 281；普通话 33 | 录音 UID 是否等于独立患者尚未核验；ASR 未人工复核；语言与任务/来源关联明显 |
| NCMMSC 长录音 | 120 个归组身份键 | 中文 | 不使用 6 秒短片；历史声学加刷新文本，归组身份依据文件名 |
| IAEAV | 209 | 西班牙语 | 患者组不是已确认纯 AD；采集组混杂未解决 |
| ADReSS | 81 | 英语 | 本地开发划分来自官方训练资料，不是官方挑战测试结果 |

统计使用成对完整观测的 Spearman 相关。少于 20 对或任一列恒定时不解释相关；没有插补，也没有 p 值。`|rho| >= 0.90` 仅表示需要复核的重叠候选，不表示删除建议。

具名任务块分别计算。例如 PREPARE 英语图片描述块有约 1,164–1,169 个成对观测；英语回忆块仅 21，叙事块仅 24。小块结果仅作初筛。`overall` 块标为未控制行任务，不用它论证跨任务通用性。

## 4. 具体发现

### 4.1 同一个量的相反表达

四份训练表中，静音占比与发声占比满足 `silence_fraction + voiced_fraction = 1`；[当前提取实现](../src/advoice/features.py)也使用同一帧集合的互补掩码。这两个数可以在不同页面显示，但不能视为两份独立患者信息。

### 4.2 话语粒度丢失会制造“新指标”

PREPARE 的三个语言块、NCMMSC 长录音和 IAEAV 中，`mean_utterance_words` 与 `word_count` 逐行相同，相关为 1。PREPARE 达到最小样本数的具名任务块也有此现象，不只是混合任务产生的相关。

[read_transcript](../src/advoice/transcripts.py:135) 对 JSON 只返回一个完整 `text` 作为一句话；[transcript_metrics](../src/advoice/transcripts.py:227)随后对话语长度取平均。这是当前代码中会产生该等式的具体机制。历史特征生成版本和各输入格式仍要追溯，不能仅凭当前代码断言每条历史记录的生成经过。

优先修复方向是保留真实话轮/话语边界；没有边界时把平均话语长度标记为不可观察，而不是把总词数包装成句法复杂度。修复效果必须通过重提取和受控评估验证，本轮没有修改该生产行为。

### 4.3 部分指标只在短样本条件下等价

PREPARE 普通话训练块中，TTR 与 MATTR50 的观测值完全相同。[_mattr](../src/advoice/transcripts.py:176) 在词数不超过窗口时直接返回 TTR，因此存在可解释的条件等价路径。后续需核查这些输入的实际长度分布，不能把条件等价推广为所有语言、所有长度下都重复。

### 4.4 相同观测进入多个状态

当前配置的 S01 与 S03 共同使用 `long_pause_rate_min`，S02 与 S03 共同使用 `voiced_fraction`。再考虑静音/发声互补，S01、S02、S03 的信息共享比只比较相同列名更多。

这证明配置存在多路径复用，不证明最终概率一定被重复放大。需要同源组干预和折外校准，检查实际影响。

### 4.5 恒定值不是正常证据

PREPARE、NCMMSC 和 IAEAV 的这些训练表中，`repair_rate_100w` 与 `patient_turn_share` 是常量。没有修正标注、没有访谈者角色可能产生这样的值；不能直接解释为“没有语言修正困难”或“患者互动能力正常”。

当前解析器在 JSON 路径把访谈者计数设为 0，并通过原文的 CHAT 修正符号计数修正次数。因此来源是否支持测量必须进入证据对象。没有这种标注时，应该是不可测，而不是临床意义的 0。

PREPARE 西班牙语/普通话及 NCMMSC 表中，四个图片内容代理指标完全缺失。这是当前提取与适用范围的缺口，不能算四项正常结果，也不能把这些列计入有效证据数量。

## 5. 独立 Agent 审查发现的结构问题

两位独立 Agent 分别审查数据/字典与计算方法。结论不是医学专家确认，作用是寻找反例。

| 位置 | 当前观察 | 对研究主张的影响 |
| --- | --- | --- |
| [证据注册去重](../src/advoice/diagnostic_agent.py:43) | 按 ID 与类型去重，不识别异名同源 | ID 唯一不等于信息独立 |
| [状态引用](../src/advoice/diagnostic_agent.py:601) | 依赖展示用的截断支持/反证摘要 | 展示完整不能证明计算依赖完整 |
| [撤销与修正门控](../src/advoice/cognitive_agent.py:739) | 阻止部分引用、抑制修正，不保证共享后代和先验重算 | “撤销”尚不能解释为从决策中完整移除信息 |
| [QC 残差化](../src/advoice/models.py:85) | Ridge 控制部分线性 QC 可预测成分 | 不等于统计独立、全面去混杂或状态彼此正交 |
| [预测融合](../src/advoice/diagnostic_agent.py:350) | 先验与 Agent 评分存在同源信息路径 | 置信度增大不必然来自新增证据 |
| [表示分支](../src/advoice/cognitive_representation_fusion.py:327) | 状态改变时音频/文本表示可保持不变 | 状态干预不能称作源信息完全删除 |

这些是代码级与合成反例证据，不是已量化的临床错误率。独立审查还指出音频片段筛空时回退完整波形的风险，见 [deep_audio_embeddings.py](../src/advoice/deep_audio_embeddings.py:41)。真正做源撤销实验时必须覆盖这个负例。

## 6. 如何生成可核验的“证明”

每个病例生成证据与决策记录：原始来源哈希、片段角色/时间、提取器版本、指标定义、同源组、参考校准版本、实际计算依赖、Agent 候选修改、检查结果和重算记录。报告使用这个记录，不把自然语言推理自述当作证明。

三个关键验证要求：

1. 重复不增益：复制同一来源的同一观测后，规范化证据数量与确定性状态计算不因复制而改变。对 Agent 的概率变化采用预设容忍度和重复调用对照，不要求随机模型逐字符一致。
2. 修订可重放：从修改前图追踪受影响节点，在修改后图重算。增量执行应与从纠正后输入完整执行相符，未受影响分支保持不变；不要求所有修改都翻转诊断类别。
3. 稳定不等于僵化：不改变事实的包装改写应稳定；相关测量纠正必须触发相应计算与版本更新。记录门控前结果、最终结果和回退率，排除“Agent 总被关闭所以很稳定”。

本轮实现了依赖图/重算日志检查器，支持修改前后两张图、共享后代、表示旁路、失效祖先、计算顺序与缓存陈旧反例。它检查的是**声明的图与日志**；尚未验证生产模型真的按日志执行，也不能窥探闭源 GPT 的神经网络内部过程。

## 7. 下一阶段顺序

1. 审定 179 项到现行提取器的版本映射，优先处理 14 个历史复用列、话语长度退化、修正/话轮不可测问题。
2. 分开展示用 trace 与完整计算依赖；实现源证据修订后的真实重算，并与完整执行对照。
3. 冻结相同数据/编码器，在训练内部比较完整、定义级去重和分组精简集合。QC 审查价值单独保留，不由分类性能单独裁决。
4. 做同事实、同模型、同预算的 Agent 对照：仅结构化、检查权限、检查且重算。分别报告预测、校准、错误证据采纳、稳定性、修正响应与成本。

“需要多少个指标”由第 3 步得出，而不是先规定 179 个都有价值，或先规定必须削减到 20 个。正式确认不能继续反复使用已经看过的官方测试结果调方案；数据污染与真实患者独立性也需要单独说明。
