# Evidence Governance：文献综述、研究定义与现有计划的缺口

研究日期：2026-09-17。范围：ADvoice、临床可解释 AI、证据约束的 LLM，以及多模态信息依赖。

性质：问题导向的范围综述和研究定位分析，不是穷尽性的 PRISMA 系统综述。逐篇来源、阅读深度和不能支持的结论见 [文献矩阵](EVIDENCE_GOVERNANCE_LITERATURE_MATRIX.csv)。本轮没有训练、改变生产预测、生成新的性能结果或绘制机制成果图。

基于本综述形成的正式概念、治理不变量、结构命题和可证伪假设见 [Evidence Governance 理论框架](EVIDENCE_GOVERNANCE_THEORETICAL_FRAMEWORK_ZH.md)；逐项允许与禁止表述见 [理论主张矩阵](EVIDENCE_GOVERNANCE_THEORY_CLAIM_MATRIX.csv)。

## 1. 结论：现有计划覆盖了一部分，但尚不能支撑完整主张

现有五阶段计划已经覆盖指标台账、重叠分析、撤销规则、精简集合和 Agent 干预实验。它不只是工程检查，也有研究设计。但目前已完成的主要是结构统计和合成契约测试，不能直接推出以下结论：

- 179 个候选指标各自提供独立且必要的信息。
- LLM 的实际决策经过了报告中展示的证据链。
- 更稳定的输出更准确，或更详细的解释更安全。
- 我们的外部数据未被基础模型预训练接触。
- 治理机制能以很少病例跨语言、跨模型、跨医学任务迁移。

会议建议应该被转化为可证伪的研究问题，而不是把这些前提写成已经取得的优势。建议主问题为：

> 在存在同源重复、测量误差、任务差异和证据修订的多模态筛查中，显式管理证据的来源、依赖和使用权限，能否减少无依据推断，并使决策对无关表达保持稳定、对真实证据变化作出适当响应，同时保留预测效用？

“效用、稳定性、忠实性、临床影响”必须分开测量。总能退回同一监督预测的系统可能很稳定，但这既不证明 Agent 有贡献，也不证明证据得到正确使用。

## 2. Evidence Governance 到底指什么

### 2.1 本项目的操作性定义

Evidence Governance 指一套可执行、可审计的规则：决定哪些观察可以作为证据进入系统，怎样保留测量语境与依赖，允许它支持什么主张，以及证据被修正或撤销后，哪些计算和报告必须更新。

这是本项目提出的操作性定义，不是宣称该术语由我们首创。2026 年的软件工程研究已经明确讨论 evidence-governance，并通过检索控制、证据充分性检查和拒答管理输出。[AGR 原文](https://link.springer.com/article/10.1007/s10515-026-00640-x)

| 对象 | 在 ADvoice 中的含义 | 不应混淆成什么 |
| --- | --- | --- |
| 原始观察 | 某次录音、某个患者话轮、某段转录 | 经模型加工后的临床结论 |
| 测量 | 按指定算法计算的静音占比、词汇指标等 | 一个无需考虑误差的事实 |
| 证据对象 | 测量及其来源、任务、角色、适用范围、误差与依赖 | 只附一个 ID 的数值 |
| 认知状态 | 多项测量对某一临床构念的估计 | 已经确认的脑机制或诊断金标准 |
| 预测 | 根据训练分布得到的风险或类别判断 | 从语音必然推出的疾病事实 |
| 报告主张 | 在授权范围内向使用者表达的观察与解释 | 模型自由补全的病史、病因或分期 |

外部医学知识与患者证据应分开登记。指南说明一般情况下如何解释，不能替代该病例缺失的检查结果。检索到类似病例，也不意味着它与当前患者是同一个证据来源。

### 2.2 六项治理操作

1. **准入**：检查来源、病例身份、任务、说话人及测量是否成立。
2. **语境保留**：保留单位、分母、阈值、参考人群、语言和测量不确定性。
3. **依赖管理**：登记同一源事件、公式等价、共享分母与跨状态复用，禁止将重复表示冒充独立支持。
4. **使用控制**：区分临床解释、模型辅助、质量控制和不可推断的用途。
5. **修订传播**：修改或撤销后，使真正受影响的计算、缓存、先验和报告同步失效或重算。
6. **发布核验**：输出必须与本次有效证据、实际运行版本和计算记录一致。

“来源存在”“引用正确”“医学推断正确”是三件事。W3C PROV 可以帮助表达实体、活动与派生关系，但来源模型本身不保证信息真实。[PROV-DM](https://www.w3.org/TR/prov-dm/)

## 3. 领域发展到了哪里

| 研究路线 | 已有代表工作 | 已经解决的部分 | 对本项目留下的研究要求 |
| --- | --- | --- | --- |
| 可解释预测与临床语音指标 | Rudin 2019；Lindsay 等 2021；SpeechCARE 2025 | 透明模型、可解释指标、跨语言特征与动态融合 | 不应将“有指标/状态/权重”本身当作创新 |
| 输出归因与临床叙事 | SpeechCARE 后续解释框架 2026；MIND 2026 | 将模型或多模态数据转成可读叙事 | 叙事是否忠实、是否误导、错误时怎样纠正 |
| 检索与引用支持 | ALCE、RARR 2023；MEDRF 2026 | 检索支持、引用评价、内容修正或预测辅助 | 引用了证据，不等于证据实际决定了答案 |
| 可执行中间过程 | Faithful CoT 2023；Concept Bottleneck Models 2020 | 中间表示可进入实际计算并接受干预 | 前提错误、概念泄漏及绕开状态的旁路仍须检查 |
| 多模态依赖分析 | 信息分解框架，NeurIPS 2023 | 区分冗余、独有信息和协同信息 | 不能用两两低相关代替独立性或价值证明 |
| 神经机制与信息流 | Circuit Tracing 2025；Faithfulness as Information Flow 2026 | 开放内部访问下的计算路径诊断与干预 | 不能直接用于只有输入输出的 GPT API |
| 临床人机协作与部署 | Xu 等 Nature Medicine 2026；SHAKED 2026 | 人的正确性、依赖行为、工作负担与使用结果 | 不能用用户觉得可信代替临床获益 |
| 数据污染与泛化 | Oren 等、Shi 等 ICLR 2024 | 在特定假设和访问条件下检测训练接触 | 本地划分无法自动排除基础模型预训练污染 |

这些路线互相补充，并不是一条“解释越来越漂亮，所以系统越来越可靠”的进步线。原始论文和阅读层级见文献矩阵；下面重点讨论对定位有实质影响的工作。

### 3.1 必须更新对 SpeechCARE 的描述

SpeechCARE 2025 的分类核心是声学、语言及人口学表示的自适应门控融合；其预处理已使用 LLM 辅助异常和任务识别，因此“它完全没有 LLM”不准确。[原文](https://www.nature.com/articles/s41746-025-02026-x)

2026 年后续工作加入 SHAP、语言特征和四阶段 LLaMA 解释。其临床有效性评价使用 70 个英语且原分类正确的病例；这不能回答模型出错时解释是否仍可靠。论文没有据此证明解释链改变了分类计算。[方法 2.5–2.7](https://arxiv.org/html/2606.27973v1)

因此，我们的候选区别不能停留在“有 Agent、有临床状态、有医生报告”。要验证的是：证据依赖是否约束实际决策，以及错误证据被纠正后是否沿所有相关路径生效。这是拟验证的区别，不是当前已超过对方的结果。

### 3.2 MEDRF 是比“纯模态权重”更接近的对照

MEDRF 结合临床资料、结构 MRI、层级分类与 RAG-LLM，处理缺失和模糊病例，并报告外部预测改善。它已经说明“监督模型加检索推理修正”不是空白。本轮核验到摘要，未据此推断它是否完整实现源撤销、同源去重或计算重放。[PubMed 摘要](https://pubmed.ncbi.nlm.nih.gov/42477097/)

后续对照应区分预测性能与治理行为。不能因为对方没有使用我们的术语，就在能力表中替它填“没有”。未在可访问文本报告的项目应标为“未核验/未报告”，不是否定结果。

### 3.3 徐旭海的工作不是“证明图越详细越好”

Xu 等的 Nature Medicine 研究比较不同解释和人机顺序，发现解释对医生与非专业者的作用不同，错误 AI 建议也可能因流畅解释而更易被接受。这是人机协作证据，不是 LLM 神经机制证据，也不能推出医生总能识别错误。[研究结果](https://www.nature.com/articles/s41591-026-04553-w)

MIND 将多模态患者信息组织成叙事和图表，经过临床共同设计及用户研究；它支持这种呈现形式值得研究，但感知决策支持改善不能替代疾病分类或患者结局验证。[MIND](https://arxiv.org/abs/2601.14641)

同团队的纵向健康 Agent 框架强调 coherence、continuity、adaptation 和 agency。我们可借鉴“稳定保留事实，同时明确修订假设”，但该文章是概念框架，不是 AD 诊断干预试验。[作者全文](https://arxiv.org/html/2604.12019v3)

对我们最直接的启发，是增加错误病例条件下的评估，而不是只展示正确病例的 trace map：使用者是否会采纳错误建议，是否能发现失效来源，是否知道哪些信息尚不可测。当前没有真实医生评估，就不能把自动评分命名为医生验证。

### 3.4 更前沿的解释研究正在检查“信息是否真的经过中间过程”

2026 年的 Faithfulness as Information Flow 用充分性、完整性、必要性研究 CoT 信息流，并尝试训练干预。作者明确承认这些指标不是完整的内部因果证明，暴露捷径也不等于消灭捷径；实验不是临床诊断。[论文及局限](https://arxiv.org/html/2605.24286v1)

这对我们的启发是一个问题，而不是可直接移植的结论：如果认知状态确实承担决策作用，修改其有效证据应对相应计算产生可检查的影响；如果原始表示或冻结先验绕开了这些状态，报告不能把状态图展示成完整预测机制。

## 4. “内部证明”需要分成四层

| 层次 | 可以证明或检验什么 | 所需材料 | 当前边界 |
| --- | --- | --- | --- |
| 来源层 | 某主张能否定位到本次病例的有效输入 | 原始文件指纹、时间、角色、版本、来源 ID | 来源可定位不等于其内容正确 |
| 执行层 | 是否按授权依赖计算，修订后是否正确失效和重算 | 实际执行日志、输入输出摘要、缓存键、可重放函数 | 声明的图通过检查，不代表真实执行符合图 |
| 行为层 | 输出是否对无关包装稳定、对相关证据变化响应 | 配对干预、相同模型和调用预算、重复运行对照 | 能检查输入输出行为，不能完整还原神经机制 |
| 神经机制层 | 特定内部表示/路径是否参与计算 | 开放权重、中间激活、激活干预及适当对照 | 闭源 GPT API 不提供这些条件 |

Jacovi 和 Goldberg 区分解释的合理性与忠实性；Turpin 等展示 CoT 可以遗漏实际影响答案的偏置信号。不能把“模型把过程说出来”作为内部机制验证。[ACL 2020](https://aclanthology.org/2020.acl-main.386/)，[NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/file/ed3fea9033a80fea1376299fa7863f4a-Paper-Conference.pdf)

本项目应将 proof generation 限定为“生成可核验的决策依据记录”，而不是“生成一段更长的思考”。其中确定性约束可以检验甚至形式化证明；测量真实性、临床构念和疾病概率仍需要独立实证。

### 一个具体但尚未运行的例子

假设某段停顿原先归给患者，后来确认它属于访谈者。系统应修订角色范围，重算受影响的患者停顿指标和认知状态，检查哪些表示、先验及预测依赖这一片段，并生成新版报告。它不必因此从 AD 翻转成 HC，但不能继续使用旧患者停顿作为支持。

若音频表示仍使用整段录音，必须明确它仍可能携带该信息。仅删除 state card 中一句话，不等于该信息已从整个系统移除。若这是“只纠正解释层”的实验，也可以做，但干预目标必须这样命名。

可核验记录应包括：源版本、证据定义、直接及派生依赖、Agent 可见输入、候选修改、验证器结果、实际重算调用、最终输出版本。固定权重与随机设置下，增量重算应与完整重算比较；随机 API 则用缓存的工具输出或分布容忍度，不要求逐字一致。

Faithful CoT 将中间程序交给确定性求解器执行，说明“可执行”比自由文本链更容易核验，但它仍不能保证从自然语言到程序的翻译正确。这也是我们验证器的边界。[原文](https://aclanthology.org/2023.ijcnlp-main.20/)

### 能从原理上推导的三个有限保证

下面是拟研究的形式化条件，不是已经证明当前生产系统满足，也不预设它们是新的数学成果。

**重复幂等。** 设 `N` 为规范化函数，仅合并经审定的同一观测、同一测量定义、同一版本及同一语境的重复对象。如果 `N(N(E)) = N(E)`，且新增重复对象 `e'` 满足 `N(E ∪ {e'}) = N(E)`，那么只读取规范化输入的确定性预测器，其输入和输出不会因该复制改变。这个保证来自输入契约，不来自要求 LLM “不要重复计权”。同源但互补的测量不能直接按此规则合并；随机模型只能讨论条件输出分布。

**修订重放一致。** 如果实际依赖完整、每个节点只读取登记的父节点、执行函数和版本固定，源修正后按拓扑顺序重算全部受影响节点，可以通过依赖顺序归纳得到与完整重算相同的结果。缓存键须包含父版本、算法、参考及政策版本。隐含文件读取、旧缓存、嵌入旁路或随机状态都会破坏假设。Agent 循环需展开成有限次调用记录，不能把有环静态图直接当作这种证明。

**发布权限封闭。** 如果每个发布路径都必须经过不可绕过的验证器，且验证器严格拒绝失效、跨病例或未授权引用，则可以保证这些已形式化的违规引用不被发布。它不保证所有被允许的主张都在医学上成立。一个正确来源仍可被错误解释，一个完整记录仍可建立在错误测量上。

这三类保证的研究价值，在于将失败归结到可检查的条件，而不是笼统宣称“Agent 更听话”。需要特别检查基础模型知识与患者证据的边界：一般医学知识可以来自模型或检索，但不得被冒充为本病例已测得的事实。禁止这种越界，不等于要求模型没有任何预训练知识。

## 5. 179 个指标：不要证明全部正交，要证明保留有理由

### 5.1 四种不同关系不能用一张相关热图代替

| 关系 | 例子或问题 | 应采用的检查 |
| --- | --- | --- |
| 定义重复 | 同一帧集合的静音比例与发声比例互补 | 公式、分母、事件与实现核对 |
| 测量依赖 | 两个指标共享同一停顿事件或相同 ASR 错误 | 来源分组、误差传播、同源干预 |
| 统计相关 | 同一语言任务内两个指标一起变化 | 分层相关及条件分析，不混合人群后解释 |
| 预测互补 | 单项弱但组合能改善判断 | 组级删除、再训练、条件贡献和独立评估 |

两个临床状态相关不意味着必须删除其中一个；反过来，两列低相关也不等于独立、有用或可靠。多模态信息分解已有冗余、独有信息和协同信息的研究框架。我们可以借其问题设定，但不宜在小样本上直接估计 179 维完整信息分解。[NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/575286a73f238b6516ce0467d67eadb2-Abstract-Conference.html)

声学、语言、对话可以是三类测量视角，但都来自同一录音时，不是三份相互独立的患者观察。其统计相关、来源依赖和临床构念关系应分别登记。

### 5.2 为什么目前不能回答“为什么正好需要 179 项”

前一轮审计发现的是历史字典 180 行、179 个名称；当前基础运行定义是 37 项，状态配置是 14 个。任务展开列、嵌入维度、历史候选和有效临床证据不是同一种计数。必须先完成版本映射和测量有效性检查，再讨论数量必要性。[本地审计结果](EVIDENCE_GOVERNANCE_INITIAL_FINDINGS_ZH.md)

前一轮已发现的三个具体入口是：静音/发声互补；部分表中平均话语词数退化成总词数；没有角色或修正标注的常量被误当作正常测量的风险。这些足以支持开展研究，但还没有证明哪些删减会改善临床预测。

### 5.3 应回答的选择问题

目标不是“保留最多特征”，而是在预先定义的预测、校准和审查要求下，寻找更小、更便宜、更可靠的证据集合。成本应包括测量资源、缺失率、误差、Agent 输入长度和临床审查负担。

可比较完整可测集合、公式级去重集合、训练内组级选择集合。mRMR 提供相关性与冗余权衡，稳定性选择检查不同重采样中的入选重复性；两者都不能自动赋予医学意义。[mRMR](https://pubmed.ncbi.nlm.nih.gov/16119262/)，[Stability Selection](https://arxiv.org/abs/0809.2932)

选择必须发生在训练内层。最终独立评估记录性能、类别召回、校准、覆盖率、群体差异与成本。质量控制指标即便不提高分类准确率，也可能是拒判和测量检查所必需，不能全部交给分类损失决定去留。

跨语言筛选也不是新问题：Lindsay 等已经研究英法语中可迁移的 AD 语言特征。我们的潜在贡献须进一步涉及测量语境、同源依赖及实际修订，而不是只声称采用了多语言指标。[研究原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8170097/)

## 6. 认知状态是否真的约束了模型

Concept Bottleneck Models 将概念作为预测中间层，使概念修正能影响下游输出；这为状态干预提供参考，但需要可信的概念监督或独立验证。[ICML 2020](https://proceedings.mlr.press/v119/koh20a.html)

后续概念模型研究指出，概念表示仍可能携带命名概念之外的信息。一个节点被命名为“词汇提取”，不等于它的全部内容都可这样解释；特别是状态嵌入与表示旁路并存时。[Leakage and Interpretability in Concept-Based Models](https://arxiv.org/html/2504.14094v3)

对 ADvoice 应分开检查四件事：状态测量是否有效；预测是否确实使用状态；报告是否准确说明使用路径；状态修正是否对所有相关路径生效。状态卡可读只能回答其中很小一部分。

若保留音频/文本嵌入以维护性能，这是合理的可检验设计，但必须把“状态可解释分支”和“未完全解释的辅助分支”如实区分。不能用前者的 trace map 代表整个预测都是白箱。

## 7. 稳定性、准确性和语言漂移如何一起研究

| 实验条件 | 期望表现 | 不能使用的替代解释 |
| --- | --- | --- |
| 原样重复调用 | 估计随机性、服务版本与采样造成的基线波动 | 将所有变化都归因给语言漂移 |
| 只改变包装措辞、证据顺序和 ID 别名 | 在事实相同条件下保持相近决策 | 改写患者转录后假设临床信息未变 |
| 复制同一观测或给重复观测换名字 | 不应因重复次数增加支持 | 把来源不同但真正新增的信息也删掉 |
| 注入无依据解释、错误质量声明或任务提示 | 拒绝越权依据，必要时重核工具输出 | 一律拒答并宣称稳健 |
| 修正真实测量、角色或适用范围 | 对依赖节点重算，并允许决策合理变化 | 要求每次修正都翻转类别 |
| 缺失某一来源 | 明确不可观察，避免正常化 | 以零值替代缺失后宣称证据完整 |

保持四组主对照：相同事实的普通输入、仅结构化证据包、结构化加执行治理、治理加精简集合。另设冻结监督预测，识别 Agent 被关闭造成的假稳定。对模型调用、信息量和预算进行控制，治理增加的延迟与拒判率同时报告。

主要观察包括配对概率差和类别变化、错误证据采纳、过时证据残留、完整重放一致性、准确率与类别召回、校准、风险-覆盖率、成本及实际 Agent 修正比例。病例是统计单位，多次调用不是新患者。

受控医学视觉语言研究已经用图像/文本扰动检查解释忠实性，并发现答案准确与解释质量可以分离。我们应借鉴这种配对设计，不应宣称首次研究该现象。[Moll 等](https://proceedings.mlr.press/v297/moll26a.html)

“不论什么 LLM 都听治理规则”应改为两个可检验主张：外部执行器能阻止哪些类型的违规输出发布；在多个固定版本 LLM 上，治理带来的效果是否一致。前者可以有条件地得到代码级保证，后者必须实验；两者都不等于模型内部永远遵循规则。

## 8. 数据污染和少样本：当前方案的明显缺口

本地患者划分只能排除本项目可控制的训练重叠。还须分别登记录音/受试者、参考校准、检索库、提示示例、历史调参，以及编码器和 LLM 预训练接触风险。基础模型是否见过公开数据库，目前不能一概确认，也不能一概否认。

ICLR 2024 已有黑箱污染检验和预训练成员检测研究，但它们有数据可交换性、似然访问或检测能力方面的条件；检测未发现不能作为“保证干净”的证书。[Oren 等](https://proceedings.iclr.cc/paper_files/paper/2024/hash/46e624c244cff669223d488defd4e835-Abstract-Conference.html)，[Shi 等](https://proceedings.iclr.cc/paper_files/paper/2024/file/e32ad85fa27be4a9868d55703f01323e-Paper-Conference.pdf)

最有说服力的增补是版本冻结后、未公开且授权使用的新病例，排除进入检索、示例和后续训练的路径。名称匿名化、翻译或改写既不能证明去污染，也可能改变临床特征。公开挑战测试集若已经反复用于调方案，只能保留为历史开发比较，不能继续视作全新确认集。

“很少案例就能学到”也要分解：是少量示例改善提示、训练小型校准器、学习状态融合，还是微调 LLM？这些实验的样本效率不同。应在同一预训练底座上画训练病例数-性能曲线，固定检索与提示样例选择，分别统计临床标签、状态标签和规则编写成本。强预训练知识不能包装成从零学习的少样本能力。

会议记录中的“64”尚未对应到明确论文或方法，本综述不把它当作已识别的比较系统。

## 9. 医学贡献与更广泛贡献分别怎么成立

### 医学贡献

目前更适合主张的研究方向是认知筛查中的证据可靠性，而不是单靠语音确认 AD 病理或所有临床分期。要证明任务、语言、角色和采集质量不同的时候，系统仍能区分真实行为信号、测量不足和不可支持的解释。

有两个不同层次的价值：自动系统是否更少使用错误/重复/失效证据；临床使用者是否因此作出更好的判断。后者需要独立的人机研究。没有医生参与时，只能报告自动规则和代理评价，不可把它们升格为临床安全性。

SHAKED 的前瞻性研究提醒我们，输出适当性与实际使用效益可以不同；工作负担和持续采用值得单独评估。[Nature Medicine 对应摘要](https://pubmed.ncbi.nlm.nih.gov/42618632/)

### 一般多模态贡献

候选贡献可以表述为：对具有共享来源、多层派生和动态修订的多模态系统，建立依赖感知的证据使用与修订协议，使决策依据可以重放和检查。

它不绑定“停顿”或“AD”这些具体名称，因此架构上可迁移到图像加报告、传感器加日志等系统。但当前 ADvoice 数据只能支持 ADvoice 范围内结论。若要声称跨领域有效，至少还需要一个非 AD 多模态任务、多个模型底座和同样严格的干预协议。

不要同时把本篇论文扩成通用多模态模型、完整神经机制解释和临床部署试验。更可控的主线是“证据依赖与修订一致性”，ADvoice 为主要实证场景；跨领域和开放权重机制分析可作为后续扩展。

## 11. 建议收敛成的三项论文贡献候选

1. **依赖感知的证据表示**：把同源观测、公式等价、不可观察及用途权限纳入指标到状态的表示，检验是否减少重复支持和无依据正常判断。
2. **可执行的证据修订**：从真实执行路径而非展示摘要生成依赖记录，使纠正能传播到相关预测与报告，验证增量与完整重算一致。
3. **区分稳定、响应和效用的评价协议**：将无关表达变化、相关证据修正和疾病预测分别评价，避免靠僵化回退获得表面稳定。

这些是可研究的贡献候选，不是已确定的新颖性、定理或性能优势。比较对象至少包含仅结构化输入、检索/引用支持、具有概念中间层的预测和后处理解释；SpeechCARE 仍是任务性能对照，但不能是唯一方法论对照。

一个能否定我们假设的结果也必须允许出现：治理减少违规引用，却不改善诊断；精简降低成本但对某些语言损失信息；状态旁路仍决定大部分预测；或规则过严造成更多拒判。这些结果决定机制是否值得保留，而不是通过更换展示方式把它们消掉。

## 12. Trace map 应该承担什么作用

后续图应由实际计算记录生成，区分“确定性计算”“学习得到的关系”“临床解释”三类边；显示共享源组、不可观察项、冲突、被撤销来源和修订前后受影响路径。局部可解释分支与未解释的表示分支应同时可见。

它可以是论文中的可审计信息流图，但不能命名成 LLM 神经电路，除非确实进行了内部激活研究。雷达形状可以汇总已验证的状态量，不应仅凭形状暗示病理诊断或概念正交。本轮不制作图，先确定它需要承载的证据。
