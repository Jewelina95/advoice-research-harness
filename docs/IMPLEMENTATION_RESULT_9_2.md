# ADvoice 9.2 实施结果

## 已完成

1. Agent 首轮工作区不再包含监督概率、预测类别、类别支持或真实标签。
2. 状态、指标、片段和质量证据使用统一类型化 ID，并由 schema、validator、融合器和报告共同解析。
3. 覆盖率改为状态、任务和分支覆盖；质量与混杂只降低修正门控，不直接增加疾病风险。
4. 新增任务族、语言、模态、质量和预测—证据冲突路由；稀有任务回退到共享父任务模型。
5. Agent 输出 0 至 4 的离散证据等级，系统将其转换为证据似然；Agent 不直接产生最终概率。
6. 病例级修正强度仅在训练集折外开发病例上选择，使用 Macro F1 改善和 Macro AUROC 非劣的联合门禁。
7. 新增相同编码器对照，分离编码器、认知状态框架和 Agent 修正的贡献。
8. 非法证据引用只进行一次盲化契约修复；仍不合法的候选回退到监督先验。
9. `make all-full` 在运行其他数据集前强制执行 PREPARE SpeechCARE 门禁。

## PREPARE 结果

- 9.2 Micro AUROC：0.8462；SpeechCARE 论文均值：0.8683。
- 9.2 Micro F1：0.6723；SpeechCARE 论文均值：0.7211。
- 9.2 Micro AUPRC：0.7011；SpeechCARE 论文均值：0.7473。
- 相同编码器下，认知框架带来 Macro AUROC +0.0601、accuracy +0.0752。
- Agent-on 相对 Agent-off 的 Macro AUROC 为 -0.0008，accuracy 为 0.0000，尚无病例分类净增益。
- 类型化证据有效率为 95.39%；报告权限和质量证据分离审计均为 100%。

## 结论边界

七项工程与方法改造已实现，认知框架本身的独立增益成立；Agent 数值修正和 SpeechCARE 优效尚未成立。PREPARE 官方测试集已被历史开发查看，不能再作为未触碰的确认性外部验证集。其他数据集按门禁规则暂不运行。

## 下一项方法升级

先补齐任务语义证据：图片描述内容单元、词语流畅性聚类与切换、记忆回忆遗漏/侵入/重复、访谈话题连贯性，并保留可定位的文本和音频片段。随后在不改变认知框架的条件下训练可复现的多语言时序主干，完成多随机种子开发集选择后，再进入新的锁定外部队列。
