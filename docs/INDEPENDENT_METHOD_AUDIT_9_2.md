# 独立方法审查记录

审查对象为 8.27 实现及 9.2 的拟议改造。独立 Agent 只读检查，没有修改代码。

## 阻断性发现

1. 8.27 的 PREPARE Agent-on 与 Agent-off 概率完全一致，Agent 实际增益为零。
2. 8.27 同时向 Agent 暴露监督先验并要求其不得改变结论，接口目标自相矛盾。
3. 大规模回滚主要来自证据 ID 生成、提示词和 validator 白名单不一致。
4. 旧 coverage 使用 top-k 指标数除以全部指标数，证据越多反而可能越低；批次归一化还会使同一病例随批次改变。
5. 每位患者单独学习自由修正参数不可识别。可学习的是跨病例共享的低容量门控函数或全局修正强度。
6. PREPARE 官方测试集已被历史开发多次检查，只能作为回顾性开发测试。
7. 旧认知状态分支权重很低，不能把监督模型性能表述成 Agent 性能。

## 审查后的调整

9.2 不让 Agent 自由输出连续概率，而是输出离散证据等级；系统将其确定性转换为证据似然。修正强度只在训练集折外开发病例上学习。新增同编码器 E0-E3 析因设计，明确分离编码器、认知状态框架和 Agent 的贡献。
