# ADvoice 9.2 方法与验证协议

## 研究边界

本系统用于认知障碍研究筛查和转诊支持，不用于确诊。PREPARE 官方测试集已经在历史开发中被多次查看，因此 9.2 将其标记为回顾性开发测试；它可以用于定位失败模式，但不能独立支撑确认性优效声明。最终优效结论需要新的锁定外部、时间外或站点外队列。

## 9.2 诊断链

1. 输入路由：按语言、任务结构、任务族、可用模态和患者语音范围建立病例输入路由，不使用疾病标签。
2. 共享表示：音频使用 mHuBERT-147，文本使用 gte-multilingual-base。与 SpeechCARE 的匹配编码器实验固定相同预训练骨干和数据切分。
3. MetricEvidence：把原始测量记录为带方向、训练折参考、可靠度、混杂、任务范围、片段定位和报告权限的证据对象。
4. StateCard：同一临床构念内的相关指标先聚合为认知状态；总体状态与任务特异状态同时保留。
5. 监督先验：多个表示分支使用训练折外预测形成病例级监督先验，测试标签不进入训练、校准或 Agent 输入。
6. 盲化证据 Agent：Agent 看不到监督先验、最终概率和真实标签，只能审查状态、指标、片段、反证和质量限制，并输出 0 至 4 的离散证据等级及类型化证据 ID。
7. 确定性分层融合：离散等级转换为证据似然；质量门控和病例路由决定修正幅度。对于 HC/MCI/AD 三分类，Agent 只校正 HC 与认知受损总量，MCI 与 AD 的内部比例由监督模型保留，避免语音证据被越权解释为疾病分期；二分类任务直接使用对数意见池。
8. 回退：非法 ID、未审查反证、不可观察状态、严重质量限制或校准样本不足时，修正强度归零，并保留监督先验或触发复测/弃权。
9. 报告：报告只读取锁定后的结论和允许报告的证据，不重新计算类别。

## 六项接口改造

| 改造 | 9.2 实现 | 稳定性约束 |
|---|---|---|
| 去除首轮概率锚定 | Agent 工作区删除监督概率、类别支持和旧修正值 | Agent 形成证据判断后，融合器才读取先验 |
| 修复证据 ID | `state:`、`metric:`、`segment:`、`qc:` 类型化注册表 | schema、提示词、validator、报告共享同一标识 |
| 覆盖率与门控 | 状态、任务、分支三层覆盖，不再使用 top-k/全部指标数 | 增加重复指标不改变 coverage；批次构成不改变病例结果 |
| 病例路由 | 单/多任务、任务族、语言范围、分支范围，加正常/受损层面的预测-证据冲突路由 | 共享模型与父任务族回退，禁止稀有任务独立拟合；三分类不允许 Agent 任意改写 MCI/AD 比例 |
| 证据似然 | Agent 输出离散证据等级，系统确定性转换为似然 | 不允许 Agent 自由生成最终概率 |
| 修正强度 | 在训练集折外开发病例上选择一个共享强度 | 正式测试前冻结；样本不足时强度为零 |

状态更新接口同时接受任务状态的完整标识，或“基础状态 ID + task_scope”的唯一组合；两种写法均解析到同一类型化注册表对象，不放宽对不存在状态的拒绝规则。

## 必须报告的析因实验

- E0：匹配编码器加普通模态门控。
- E1：E0 加 MetricEvidence、StateCard 和任务路由，不启用 Agent 修正。
- E2：E1 加先验盲化 Agent、病例路由和验证集学习的受限修正。
- E3：向 Agent 显示监督先验，仅作为锚定效应审计，不作为主结果。

主比较是 E2-E1，它回答 Agent 是否带来真实净增益。E1-E0 回答认知证据框架是否带来增益。每项同时报告修正正确数、破坏原正确数、净修正数、弃权覆盖曲线、macro AUROC、macro F1、accuracy、Brier、log loss 和 ECE。

## 禁止事项

- 不根据官方测试集结果选择权重、阈值、路由或提示词。
- 不把单次运行与 SpeechCARE 十次训练均值直接解释为统计优效。
- 不把 Agent 生成的语言当作医学事实或确诊。
- 不因目标是超过基线而隐去失败数据、改变测试划分或筛选有利随机种子。
