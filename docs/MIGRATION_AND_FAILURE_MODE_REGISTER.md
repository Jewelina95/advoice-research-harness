# 迁移边界与 Failure Mode 登记

## 旧资产如何使用

8.20/8.21 的 HTML 只作为报告章节、双层评估叙事和图表信息密度参考。8.27 不复制旧数据适配器、特征函数、训练代码或测试；接口和测试依据本目录的规格重新实现。旧训练产物、旧概率和手工汇总结果只用于历史回归审计，不进入 8.27 正式评估。

## 已知结构性缺口

| 缺口 | 风险 | 8.27 修复 | 验收证据 |
|---|---|---|---|
| Agent 主要是报告阶段 | 证据链与预测链连接弱 | Agent 形成带引用的候选判断，模块 B 和验证器决定是否有限采纳 | Agent ablation、修正安全性、trace |
| 可靠度是单一分数 | 无法知道低可信来自哪里 | 拆成覆盖、角色、对齐、稳定性、参考支持和 QC 惩罚 | 字段完整性和干预测试 |
| 任务可观察性与权重混淆 | 不适用状态可能参与预测 | 独立 observability mask，再算 reliability 和 learned contribution | 不可观察状态为 unavailable 且权重为零 |
| 多任务先汇总再融合 | 抹平 Cookie、流畅性、回忆等差异 | 保留 overall 状态并新增折内任务状态 | task-state ablation 与同任务 trace |
| 病例包可能是大段文本 | 难验证、易泄漏 | JSON Schema、只读工具、稳定 ID、标签隔离 | schema 和泄漏测试 |
| 自动报告分数被误读 | 不能代表医生可用性 | 自动结构评分与医生实验分开 | 报告注明评分来源 |
| 旧输出跨运行混合 | 数值不可复现 | run manifest、哈希和原子化 latest 发布 | 全部 artifact 共用 run ID |

## 数据集特异 failure mode

### IAEAV

历史上存在采访者、采集方式或设备与标签共线的风险，接近 1.0 的结果首先视为 shortcut 警报，不视为临床突破。修复包括 interviewer/source/device-only 负控、按采集组切分和角色移除审计。未通过前只报告偏倚审计，不进入总体临床结论。

### ADReSSo progression

这是纵向变化任务，单次病例状态不等于进展信号。需要患者成组切分、成对访视差值/轨迹和缺失访视处理。修复前不允许用静态诊断模型解释进展。

### PREPARE

多任务数据不能先做跨任务平均。需要任务路由、任务特异状态和与对比论文一致的 split/标签/指标协议。长音频是主输入；短窗口只作为编码器内部片段，不把六秒剪辑当独立患者。

### TAUKADIAL 与 NCMMSC

中文/跨语言词法、句法和 ASR 指标必须使用语言适配的分词与参考。不能只为中文建特殊词典而忽略西班牙语和英语；应采用共享状态定义、语言特异测量器和语言内训练参考。跨语言 pooled reference 不足时状态标记 unreliable/unavailable。

### DementiaBank Pitt

接近完美结果必须检查同一说话人重复访视、同源音频、转录模板和元数据泄漏。正式 split 以 speaker group 为单位，并做近重复和文本模板审计。

### DementiaNet

公开视频缺少标准任务、角色和采集控制，只作为外部泛化/压力测试。设备、剪辑和公开人物身份不得进入疾病判断。

## 训练 failure mode

- 小样本训练深层门控导致折间权重不稳定：改用低容量模型并报告 seed/fold 分布。
- 按最终 test 反复调权重：禁止；超参数只在内层 CV 选择。
- Agent 修正提高 accuracy 但降低 AUROC/ECE：模块 B 必须同时通过判别与校准非劣效门槛。
- 缺失模式预测标签：报告 missingness-only 负控并限制缺失指示器。
- 数据集名称成为 shortcut：仅用于审计和报告，不作为预测输入。

## Agent failure mode

- 引用正确但解释越界：医学 Skill 和报告权限双重限制。
- 忽略反证：提交前强制 `counterevidence_ids` 或明确“未发现可用反证”。
- 概率随证据顺序变化：顺序扰动稳定性测试。
- 把报告语言流畅当临床正确：结构评分、事实评分和医生评分拆开。
- 回退后重复同一错误：同一 violation 最多重试一次，之后 abstain/fallback。

## 不武断的判定规则

任何升级是否保留，由预注册门槛决定，不由“必须超过”决定：

1. 同协议、同 split、同标签、同病例。
2. 主要效应报告 95% CI 和重复 seed。
3. 预测性能至少非劣效，校准和 evidence audit 不恶化。
4. 外部验证和子组结果不能由内部 CV 替代。
5. 未通过时保留失败结果、原因和回退版本，不改写数字。
