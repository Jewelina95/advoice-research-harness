# 报告与评估固定规范

## 报告体系

每次完整运行固定输出三类 HTML，不能因新增数据集改变章节结构。

### system_report.html

展示本次运行真正执行的系统，而不是设计愿景：

1. 运行 ID、代码版本、配置哈希、数据快照和环境。
2. 数据来源、任务/语言/标签分布、纳入排除和 split。
3. 当前启用的指标、状态、任务可观察性和 planned 项。
4. 两个监督模块、Agent、Skill、回退和最终锁定流程。
5. 一条 label-free 病例包实例及其 trace。
6. 未实现、未运行和失败项目。

### evaluation_report.html

学习 8.20/8.21 示例报告的双层叙事、信息层级和图表密度，但不继承旧代码或数值；报告数据必须全部来自 8.27 同一 run：

- 开头说明三条件、数据协议、样本量和主要限制。
- Layer A 一张总图 + 分析图。
- Layer B 一张总图 + 分析图。
- 每个数据集单独结果和失败模式。
- 不把不同 split、不同协议或文献数字画成直接胜负。

### clinician_case_report.html

每个数据通道至少选择一个 held-out 病例。报告只显示锁定结论、认知状态、原始指标与参考、片段、反证、采集限制和复核建议。真实标签在独立的研究评估附录出现，不进入医生正文。

医生正文不是 Agent 的第二次自由生成。锁定决策先产生 `impression_code + action + class/probability or value + template_id`，再由确定性模板渲染；文字不得改变类别、概率、证据选择或医学用途边界。

## 三条件定义

- **B1 traditional ML**：预注册的传统声学/文本特征与正则化监督分类器；不使用 StateCard、Agent 或预训练高维表示。补充模型可放附录，不改变 headline baseline。
- **B2 direct LLM**：按数据通道接收与 B3 相同的原始可用模态（音频和/或转录）及基本任务说明，直接给出终点预测和报告；不接收 B3 的指标、StateCard、监督先验、Skill 或证据工具。
- **B3 ours**：双表示、MetricEvidence、StateCard、监督模块 A、单一诊断 Agent、CooT 风格回退、监督模块 B 和锁定报告。

B1/B2/B3 必须使用相同病例 split、标签定义和主评估集。

## Layer A：医学预测与筛查必须报告

### 核心区分和分类

- AUROC 及 bootstrap 95% CI。
- AUPRC 及阳性患病率基线。
- Accuracy、balanced accuracy、macro/weighted F1、MCC。
- TP、TN、FP、FN 或多分类混淆矩阵。

### 临床操作点

- 预注册高敏感度操作点的 sensitivity、specificity。
- PPV/NPV，并在目标人群患病率场景下重算。
- 漏诊率和误报率。
- 若多分类含 MCI/进展任务，按临床任务分别定义操作点，不能套用 AD vs HC 阈值。

### 校准和效用

- Brier score、ECE、可靠性曲线。
- near-threshold error 与 high-confidence error。
- 决策曲线/净获益，仅在阈值和目标人群用途预注册后报告。
- 允许 abstain/retest 时，同时报告 coverage、selective risk、拒绝病例构成和覆盖固定时的性能，避免通过大量拒绝抬高准确率。

### 稳健性与外部效度

- bootstrap CI 与重复 seed。
- B1/B2/B3 使用相同 held-out 病例做配对 bootstrap；多数据集/多终点推断预注册层级检验或 FDR，样本不足的子组只描述不检验。
- 年龄、性别、语言、任务、采集来源、设备/QC 子组。
- QC-only、no-duration/no-loudness、source/device-only 负控。
- 留一任务/留一语言/预声明外部数据集验证。
- 数据泄漏、同源片段和近重复审计。

## Layer B：框架特异验证

Layer B 不重复 AUROC，而是验证 B3 的核心机制是否真实存在。

1. **MetricEvidence 完整性**：必填字段、折内参考、可靠度分解、任务和片段是否齐全。
2. **StateCard 完整性**：状态是否有可观察性、支持、反证、置信度和不可用原因。
3. **证据链忠实度**：报告结论能否回到状态、指标、任务、片段和原始音频/转录。
4. **报告权限审计**：QC 和模型辅助证据是否被阻止成为疾病依据。
5. **Agent 证据遵从率**：提交的每个判断是否有有效引用，是否检查反证。
6. **回退正确率**：人工构造违规输入时，系统是否定位并撤销错误证据/状态。
7. **决策稳定性**：提示等价改写、证据顺序变化和重复调用下的类别/概率变化。
8. **有限修正安全性**：B3 修正相对模块 A 的 AUROC、Brier、ECE 非劣效；错误修正率和回退率。
9. **机制消融**：无 Skill、无片段、无反证、无状态、无回退、无模块 B、concept-only、raw+state。
10. **临床报告质量**：证据完整性、临床可解释性、安全与校准、筛查/转诊有用性、可追溯性，各 0–5。自动评分和医生评分必须分开标注。

## 固定总图

### Layer A 总图

一张多面板图，固定包含：

- A：分类终点的各数据集 B1/B2/B3 AUROC 与 95% CI；连续/序数/配对变化终点使用预注册的 MAE、RMSE、相关/一致性或相应分类指标，不能硬画 AUROC。
- B：balanced accuracy、macro F1、MCC。
- C：高敏感度操作点的 specificity 和 NPV。
- D：Brier、ECE 与高置信错误率，低值更好。
- E：关键子组/外部验证差异。

### Layer B 总图

一张多面板图，固定包含：

- A：证据链完整性、引用忠实度、权限合规率。
- B：Agent 证据遵从、反证检查、回退成功率、稳定性。
- C：模块 A -> B3 的判别、校准和错误修正变化。
- D：B2 与 B3 报告五维评分，自动与医生来源分开。
- E：消融对性能、可追溯和安全的影响。

所有图使用英文轴和图例、直接标注关键数值、统一条件颜色；中文正文解释医学含义、数值方向和限制。图模板固定，新增数据只改变数据，不改变布局逻辑。

固定指的是信息层级和视觉语法，不是固定像素。数据集过多时允许分页或分面，不能缩小字体塞进一张图。

## 发布门槛

任一条件满足时不得把运行标记为正式结果：

- manifest/split/leakage 审计失败。
- 测试标签进入病例包或 Agent trace。
- 主要指标缺失置信区间。
- B3 修正使判别或校准显著恶化且未回退。
- QC-only 达到高判别力而未降级该数据集。
- 报告引用不存在或越权证据。
- 报告、CSV、图和模型来自不同 run ID。

## 工程运行指标

Layer B 同时记录 Agent 调用失败率、schema 无效率、回退重试率、平均/95 分位延迟和 token/病例成本。这些指标不证明医学有效，但决定系统是否可实施。
