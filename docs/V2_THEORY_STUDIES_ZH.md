## 3. 理论上可以再推进的四点

### 3.1 稳定性可以写成一个界，而不只是实验观察（Q1）

在 v2 的可分解预测下：

```
logit(x) = Σ_s β_s · z_s(x) + γ · r(x) + b
```

LLM 只通过两条受控通道影响结果：Agent 测量出的状态分 `z_s`（s ∈ A，A 为 Agent 派生的状态集合），以及作为堆叠候选的独立判断 `a`（系数 `w_a`）。设 LLM 漂移使这些量变化 `Δz_s`、`Δa`，其余确定性部分不变，则

```
|Δlogit| ≤ Σ_{s∈A} |β_s| · |Δz_s| + |w_a| · |Δa|
```

这是一个由结构直接得到的上界。它说明三件事：

1. 治理把 LLM 漂移对结论的影响限制在“学到的权重 × 测量漂移”之内。条件 B 没有这个界，LLM 的任何漂移直接就是结论的漂移。
2. 测量漂移可以再压低：每项 Agent 测量做 k 次采样取均值，在采样近似独立时方差约降为 1/k；不一致程度同时作为可靠度，可靠度低的测量自动降权。
3. 权重 `β_s`、`w_a` 是从标签学的。如果某个 LLM 的测量又飘又没用，它的权重会被学小，界自动收紧。也就是说，“不论哪个大模型都要服从 Evidence Governance”在这里有精确含义：模型只能通过有界、可审计、按证据价值加权的通道影响判断。

可检验的推论：

- 同一病例重复调用、换措辞、换模型时，C 的结论翻转率显著低于 B；
- C 的实测 `|Δlogit|` 不超过上式的界（这个检验在真实系统上也能直接做）；
- 跨模型（GPT / Claude / DeepSeek）的结论一致性：C 显著高于 B。这是对“不论哪个模型”的直接检验。

稳定性不能用僵化换来。所以同时要做有效干预：修正一个真实测量后，结论必须按依赖关系变化（框架的忠实性定义）。“稳定但不响应”在阶梯实验里要单独报告。

### 3.2 证据准入只用一个判据（Q2、Q3，并与 Agent 增益统一）

v2 方案里 Agent 增益的条件是 I(Y; a | X) > 0。同一个判据可以作为所有证据组的准入规则：

> 证据组 e 进入预测，当且仅当在已有证据集合 E 下 I(Y; e | E) > 0 且稳定可复现；或者它承担不可替代的安全作用（QC、拒判、权限），这时只进入可靠度和报告，不进入预测。

这样“为什么是这些 feature”“为什么要 Agent”“哪些要筛掉”是同一个问题，不需要三套说法。具体做法：

1. 先按定义和来源合并（同源组），去掉严格等价项，比如静音/发声只保留一个。
2. 在训练集嵌套交叉验证中，用条件增量（逐组加入或删除的 OOF log-loss 变化）和稳定选择（多次重抽样中被选中的频率）衡量 I(Y; e | E)。高维部分信息分解不可靠，分析单位用同源组或状态，而不是 179 列。
3. 画证据复杂度 Pareto 曲线：横轴是有效证据组数，纵轴是 OOF 性能与校准。“需要多少个 feature”由曲线的拐点回答，而不是事先规定。
4. 正交不是目标。临床状态本来就相关；要证明的是“同源不重复计票”和“每组都有条件增量或安全作用”。

### 3.3 Agent 当测量仪器，本身就降低了污染风险（Q4）

DementiaBank 系列的转录在网上流传多年，基础 LLM 很可能见过，本地 split 控制不了这一点。

关键区别：

- Agent 当分类器（条件 B）时，污染可以直接把记住的标签变成虚高准确率，而且无法从输出上发现。
- Agent 当测量仪器（v2 的 C）时，它输出的是“提到了哪些信息单元”“哪句偏题”。这些可以与人工标注逐项核对，记住的标签无法在不被发现的情况下抬高测量的有效性。最终的类别映射由监督层在本地训练折内学习。

所以 v2 的 Agent 角色设计本身就是对 Q4 的部分回答。剩余风险用四个办法处理：

1. 污染台账：每个数据集的公开时间、在线可得性与各模型知识截止的关系。
2. 记忆探针：让模型续写转录、补全病例 ID。阳性说明有风险，阴性不能证明没见过。
3. 留一数据集外验证：每次留一个数据集完全不参与训练和选择。
4. 真正的未见数据：晚于模型知识截止的数据，或自采的私有数据。这是唯一能给出强结论的一级。

### 3.4 trace map 是显式信息流图（Q6）

机制可解释性的做法是事后从模型内部恢复出一张信息流图。我们的 trace map 是在计算之前就规定好的显式图：结论只能沿着这张图上的边获得信息。

论文里的写法是：trace map 加干预实验。删掉图上某条边对应的证据，结论按 β·Δz 变化；删掉图外的信息（例如换无关措辞），结论不变。这就证明信息确实沿着这张图流动，而不只是画了一张图。

若要更进一步回答“LLM 内部是否真的在用被引用的证据”，需要换成开放权重模型（例如开放版本的 Qwen、Llama、DeepSeek），做激活修补或归因图分析。这是独立的一项工作，结论只适用于开放模型。评论里提到的“tinghao”，可能是指做这类内部机制分析的人或工作，需要你确认。

## 4. 少样本（Q5）

论证结构：治理规则大多与标签无关，需要从数据学习的只有健康参考、状态权重和阈值；层级收缩让小数据集借用其他数据集学到的共享权重。所以 C 学到可用判断所需的标注病例应少于“从 embedding 直接学”的模型。

实验：在中等规模数据集上，预注册 0、4、16、32、64、全部 个适配病例的学习曲线。每个预算做多次患者级重抽样，比较 C、A+（embedding 模型）和 B。如果“64”在老师原意里是别的东西，以确认后的含义为准。

## 5. 与 v2 工程顺序的对齐

这些研究和 v2 的修改有先后依赖：v2 会改变 metric 定义、新增 Agent 测量、改变健康参考，现在跑的重叠统计到时都要重跑。所以顺序是：

| 步骤 | 内容 | 对应 |
| --- | --- | --- |
| 1 | 修复已发现的测量问题：平均话语词数在无话语边界时设为不可观察；修正率、轮次占比在无标注时设为不可观察；静音/发声合并为一个来源组；四个同源“语义”名称去掉 | Q2、Q3；v2 阶段 1 |
| 2 | 输入层（词级时间戳、说话人分离）和新增 Agent 测量 | v2 阶段 2、5 |
| 3 | 冻结证据 schema | — |
| 4 | 重叠、条件增量、稳定选择、Pareto 曲线；留一数据集外 | Q2、Q3、Q4 |
| 5 | G0–G3 治理阶梯 × 三家模型；无关/有效干预；漂移界的检验 | Q1、Q6 |
| 6 | 少样本学习曲线 | Q5 |
| 7 | 开放权重模型内部机制（可选，单独一项工作） | Q6 |

步骤 1 和 4 不需要 API，可以在 v2 阶段 1 结束后立即开始。

## 6. 这条线对论文的意义

方法论文最需要的是“为什么可信”，而不只是“分数多少”。四个可写成主结果的命题：

1. 结构稳定性界：LLM 漂移对结论的影响有可计算的上界，实测不超界，且跨模型一致性高于纯 Agent。
2. 单一准入判据：证据集合由条件信息增量决定，给出 Pareto 曲线和最小充分集，回答“为什么是这些 feature”。
3. 测量式 Agent 抗污染：Agent 测量可以逐项核验，类别映射在本地学习。
4. 显式信息流：trace map 加干预实验，证明结论沿规定的路径获得信息。

这四条加上 v2 的性能结果（追平主干、MCI 与校准优势、跨数据集泛化），才构成足以支撑后续医生读片实验的方法学基础。
