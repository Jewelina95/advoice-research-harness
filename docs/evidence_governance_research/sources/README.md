# Research audit trail

This directory records source provenance for the Evidence Governance study.
Patient-level data and private analysis outputs are excluded.

- Literature synthesis: `../../EVIDENCE_GOVERNANCE_LITERATURE_REVIEW_ZH.md`
- Source matrix: `../../EVIDENCE_GOVERNANCE_LITERATURE_MATRIX.csv`
- Meeting-comment protocol: `../../EVIDENCE_GOVERNANCE_MEETING_COMMENTS_PROTOCOL_ZH.md`
- Private reproducible outputs: `.local/evidence_governance/` (not for publication)

The literature matrix separates primary empirical papers, reporting standards,
and conceptual sources. Citations support method choices; they do not establish
that the local implementation satisfies those methods.
