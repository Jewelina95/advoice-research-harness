最新版 Evidence Agent：五组同病例消融

本报告使用 GitHub main 的最新版联合函数和 PREPARE 9 个完整 case audit。五组共享 frozen probability、pre/post StateCard、blind ordinal evidence 和类别顺序，仅切换状态、Agent screening 与 Agent staging 权限。

这是验证管线可行性的 9 例 pilot，不是独立测试集，也不能据此声称超过 SpeechCARE。它替代了上一份错误使用旧 B2 的比较。

五组定义

仅监督Frozen supervised probability
仅 AgentEqual-prior blind evidence
监督 + 状态Agent 审查后的状态变化
监督 + Agent独立 screening/staging evidence
完整联合监督 + 状态 + Agent

候选选择：完整联合模型。仅 Agent 不足以独立诊断；状态修正和独立 Agent evidence 分别改善不同病例；两者与监督主干同时启用时，在这 9 例中实现互补，并取得最低 log loss。

为什么这次结果不同

旧比较使用 transcript-only B2 和 state-only 分类概率。新版使用合法 Evidence ID 驱动的审查交易、审查前后 StateCard 的相对变化、盲态 ordinal evidence、HC/impairment screening 与 MCI/AD staging 分离，以及冲突感知门控。Agent 不是复制监督概率，也不是对所有病例施加固定加权。

正式验证门槛

下一步冻结该五组定义，在更大的开发集校准 state、screening、staging 三类权限，再在未参与选择的 PREPARE 同协议测试集运行。只有完整联合在 Macro-F1 提升且 AUROC、log loss、Brier 不劣时，才升级为正式模型。
