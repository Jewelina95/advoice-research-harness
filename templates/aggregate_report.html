Framework revision

1. 本轮修改了什么

本轮没有更换研究目标，而是修正会直接影响证据有效性和结果可信度的环节：病例标识、任务参照组、通道证据权限、质量控制残差化、干预检验和报告边界。新增 NCMMSC 2021 长录音作为独立中文通道，六秒片段不进入主分析。

本轮复现实验范围：本报告由 run-all-processed 生成，复用 8.13 已冻结的预处理结果、B1/B2、MetricEvidence 和片段表；本轮重新计算状态校准、条件 C 融合、诊断 Agent、病例报告与评估。它不是从原始音频重新提取全部特征的端到端运行，二者不能混写。

图 0. 本轮框架修订及其对应防止的失败模式。修改项全部进入可执行流程，而不是只写在汇报文字中。

病例与切分

跨任务病例编号唯一；训练测试继续按受试者分组，避免同一人跨集合。

参照校准

诊断任务使用配置中的正常组；进展任务使用“未进展组”，不再硬编码健康组。

证据对象

每条指标同时记录方向、可靠度、缺失、混杂和报告权限，并随数据通道变化。

诊断 Agent

Agent 读取病例级状态、任务轨迹和证据质量，在受限范围内修正基础风险；门控为零时严格退回基础模型。

报告边界

报告文本只能使用已锁定的决策轨迹和允许报告的证据；不能在生成阶段再次改变风险。

图 1. 当前完整系统。监督学习模块负责稳定的基础概率与受限校准；单一诊断 Agent 读取任务路由、MetricEvidence、StateCard 和片段轨迹，参与受证据门控的风险修正，并把同一条决策轨迹转成医生报告。Agent 不是自由改写分类器输出，也不是只负责写文字。

实现与结果边界：传统声学先验作为“仅供模型使用、禁止写入疾病解释”的分支已经进入代码，并在 ADReSSo progression 上完成验证；PREPARE、TAUKADIAL、IAEAV 和 NCMMSC 的本页结果生成早于这项最终集成，因此不把该分支写成这些数据集已经取得的性能增益。
Experimental design

2. 三个条件比较什么

B1：传统声学机器学习

以 MFCC、谱特征、能量、过零率等低层声学特征训练正则化分类器。它回答：只依赖传统声学表征时，模型能达到什么水平。

B2：直接诊断代理

直接读取转录文本或音频摘要，生成风险判断和诊断依据；不经过指标证据、临床状态和报告权限控制。

B3：单一证据诊断 Agent

两个小型监督模块先在训练折内形成跨分支概率并冻结修正边界；Agent 再读取 MetricEvidence、StateCard 和片段轨迹，在边界内修正风险，并输出同一条可追溯医生报告。

认知型 Agent 的具体含义：系统把“查哪条证据、比较哪个正常参照、判断证据是否受任务或录音质量污染、何时退回基础模型”写成可执行诊断步骤。Agent 的工作区包含病例事实、状态假设、支持与反向证据、任务范围和不确定性；它调用这些证据参与有限风险修正，再生成初筛与复核建议。这不是给 GPT 一段自由 prompt，也不是把“Cognition AI”当作未经验证的模型名称。

独立数据任务

每个数据集分别切分、训练、校准和报告；诊断、疾病进展、二分类与多分类不会混成同一个标签空间。NCMMSC 使用长录音，并以说话者为独立划分单位。

Pre-specified endpoints

3. 评估标准为什么分成 A 层和 B 层

A 层回答模型是否具备医学预测与筛查研究的基本完整性；B 层回答我们的结构化证据框架是否真正解决传统声学模型和直接大模型不能解决的问题。两层不能互相替代。

A 层：医学预测与筛查必须报告

指标组核心指标回答的问题
区分能力AUROC + 95% CI、AUPRC模型能否把不同临床标签排序分开；类别不平衡时阳性识别是否仍可靠。
固定阈值分类Accuracy、Balanced Accuracy、Macro F1、MCC在实际分类阈值下总体是否判断正确，以及不同类别是否被均衡处理。
筛查操作点Sensitivity、Specificity、PPV、NPV、Specificity@Sensitivity≥0.85高敏感度初筛时会漏掉多少患者、误报多少健康人，阳性与阴性结论是否可信。
概率安全Brier、ECE、校准斜率/截距、高置信错误输出概率能否被当作风险使用；高置信错误定义为最大预测概率至少 0.80 但分类错误。
错误结构TP/TN/FP/FN、FNR、FPR、阈值附近病例比例准确率背后具体是什么错误，是否因类别比例而产生误导。阈值附近病例定义为最高与次高类别概率差不超过 0.10。
鲁棒性与负控QC-only、去时长/响度控制模型是否主要学习了设备、录音质量、时长或能量捷径。

B 层：框架特有验证

验证对象计算指标回答的问题
MetricEvidence 完整性规定字段完整比例每条原始指标是否带有方向、可靠度、缺失、混杂与报告权限。
StateCard 完整性状态字段完整比例状态判断是否包含严重度、置信度、支持证据和反向证据。
分支贡献回溯病例级贡献覆盖率最终风险是否能追到语言、言语行为和辅助声学分支。
证据片段忠实度有原始时间片段支持的状态比例报告结论是否能回到具体音频区间或转录片段。
参考状态压力测试纠正状态后真实类别概率不下降比例命名状态是否实际参与模型决策；这是机制压力测试，不是因果证明。
消融实验完整融合 − 仅状态 AUROC原始表征和动态分支是否提供了状态层之外的增量。
医生报告审计证据、解释、安全、用途、追溯共 25 分报告是否比直接代理更完整、更可核查，并明确不确定性和下一步建议。

区分能力

AUROC 只回答排序能力，不等同于可用筛查器。必须结合准确率、MCC、AUPRC 和操作点一起解释。

筛查操作点

Specificity@Sensitivity≥0.85 直接显示在优先降低漏诊时需要付出多少误报代价；多分类或非筛查任务不强行计算该指标。

负控

Ours 与 QC-only 的差距若接近零，该通道即使 AUROC 很高也不能作为强临床证据。

Layer B

5. 框架是否解决 B1、B2 与旧系统的失败模式

B1 可以给出分类，但不能把风险追到语言内容和可审查状态；B2 可以生成文字报告，但报告与预测之间缺少受约束的证据链。B3 的 Agent 必须同时证明两件事：其证据修正确实参与预测，并且每次修正都能回到允许使用的原始指标、状态和片段。

图 B. 框架验证总图：逐数据集证据契约、B2 与 B3 报告质量、相对基线 AUROC 增益，以及状态修正、完整融合、任务路由和原始片段回溯。颜色只表示是否达到预设检查线，格内数字保留实际值。

相对 B1 的增量

不仅比较 AUROC，还要求最终结论具有状态层、分支贡献和原始证据回溯。

相对 B2 的增量

Agent 不能自由编写理由：输入是结构化证据工作区，风险修正受可靠度和混杂门控，报告只能复述同一条决策轨迹。

相对旧条件 C 的增量

Agent 从报告生成器升级为受约束的诊断参与者；基础预测、证据修正和文字沟通仍保持清晰边界。

ADReSSo progression

测试集只有 12 名受试者，宏平均 AUROC 的置信区间极宽。B3 的概率校准较好，但排序被少数病例改变；这个任务需要重复分组交叉验证或官方标签，而不是继续增加模型复杂度。

TAUKADIAL

旧版把中英文录音先汇总成一个病例级语言指标，中文按字符切分，导致词数、词汇多样性和功能词比例不可比。本轮改为语言特异分词、训练折内同语言参照和双语证据范围，再重新训练。

PREPARE

旧版丢失了图片描述、句子朗读、语义流畅性、故事回忆、个人叙事和语音助手之间的任务差异。本轮使用公开逐病例任务标签重建任务特异状态；仍未完成 SpeechCARE 级别的端到端编码器联合微调。

NCMMSC 2021

主分析只使用 30–60 秒长录音。六秒短片段保留在原始归档中，但纳入分析计数必须为 0；删除原始文件不会提高方法有效性，因此采用可审计排除而非物理删除。
