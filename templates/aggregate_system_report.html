1. 一个诊断 Agent，两个小型监督模块

基础监督模块先从语言、语音行为、辅助声学、多语言文本和多语言音频表示形成折外概率。第二监督模块只在训练折内学习证据修正上限、门控与概率校准，并在测试前冻结。推理时，单一证据诊断 Agent 检查 MetricEvidence、StateCard、任务轨迹、反证和质量混杂，只能在冻结边界内修正基础概率。医生报告读取同一条锁定决策轨迹，不另起自由诊断过程。

4. 指标先在状态内部融合

同一临床构念下的相关指标不重复投票。系统用医学方向、预设权重、病例质量和可用性形成状态分数，并同时保留支持证据、反证和源时间片段。单任务数据只生成总体状态；多任务数据同时生成总体状态和任务特异状态，而且每个训练折只用该折训练参考组建立任务基线。每个分支再比较总体状态与总体加任务状态两个候选，只有配对训练折增益下限达到阈值时，任务状态才进入最终预测。

5. 状态、深层表示与 Agent 受控融合

临床状态负责医学解释；冻结的 multilingual E5 与 mHuBERT 表示只负责补充预测信息，不能写成疾病机制。mHuBERT 以五秒重叠窗口编码，并由小型片段注意力池化器学习哪些局部变化值得保留。两个监督模块先在训练数据内形成基础概率并冻结修正边界；Agent 再根据证据覆盖、可靠度、任务一致性和混杂负担提出修正。门控为零时最终概率严格退回基础模型。
