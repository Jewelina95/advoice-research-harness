2. A 层：医学预测与筛查必须报告的结果

AUROC 和 AUPRC 衡量区分与排序；准确率和宏平均 F1 衡量固定决策下的整体与类别平衡；ECE 和 Brier 衡量概率能否作为风险使用。三分类结果同时保留 HC、MCI、AD 混淆矩阵，不把 MCI 隐藏在二分类平均值里。

本轮不能得出 Ours 在预测性能上超过 B1。B1 的宏平均 AUROC / 准确率为 {{ '%.3f'|format(summary.layer_a.B1.macro_auroc_ovr) }} / {{ '%.3f'|format(summary.layer_a.B1.accuracy) }}，Ours 为 {{ '%.3f'|format(summary.layer_a.Ours.macro_auroc_ovr) }} / {{ '%.3f'|format(summary.layer_a.Ours.accuracy) }}。Ours 的优势出现在校准，ECE 为 {{ '%.3f'|format(summary.layer_a.Ours.ece) }}，低于 B1 的 {{ '%.3f'|format(summary.layer_a.B1.ece) }}；但这不足以替代区分性能结论。
B2 的宏平均 AUROC / 准确率为 {{ '%.3f'|format(summary.layer_a.B2.macro_auroc_ovr) }} / {{ '%.3f'|format(summary.layer_a.B2.accuracy) }}，说明直接让大模型读取未经人工校验的 ASR 转录不能构成可靠基线。所有数值来自官方测试受试者，不是训练集拟合值；95% CI 保存在运行工件中。
质量控制捷径仍然明显。QC-only 的宏平均 AUROC 达到 {{ '%.3f'|format(summary.layer_a.QC_only.macro_auroc_ovr) }}，与主模型并未充分拉开。当前结果不能支持跨设备、跨中心稳健性或临床部署主张，必须继续做来源分层和外部验证。

No-duration/no-loudness 检查移除时长和响度后判别能力是否保留；QC-only 只使用时长、剪切、信噪比代理和响度。
