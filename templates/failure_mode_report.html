2. TAUKADIAL：双语文本被错误地压成英语式指标

当前中文按单个汉字计词，中文代词、停用词和填充词词典不完整；因此词数、语速、词汇多样性、代词率和内容词率不能与英文使用同一标准。固定 0.75 的 ASR 可靠度也没有反映中文、英文和代码切换的真实识别质量。

4. 可执行修复顺序

P0

P1
修表征
在训练折内微调 multilingual E5/mHuBERT，保留现有 MetricEvidence/StateCard 作为约束和辅助损失；不复制 SpeechCARE 的无约束模态权重。
验收：10 seed PREPARE 均值与置信区间；状态分支消融不再接近零；西班牙语性能不恶化。
P2
修融合与 Agent 安全门
分支只有在外层折 AUROC 稳定高于 0.5 且方向一致时才能进入；Agent 修正必须同时改善 AUROC、Macro F1，且多数外层折非负，否则 alpha=0。
验收：TAUKADIAL 改判 helped≥hurt；progression 在小样本下自动回退基础模型；报告仍与数值决策同轨。
P3
重新锁定评估
内部开发只看训练/验证；官方测试不再反复用于选模；增加官方盲测或未参与开发的外部数据。
验收：同协议、同标签、同测试集对比；给出 bootstrap/10 seed CI、语言/任务/语料亚组和失败病例审计。
