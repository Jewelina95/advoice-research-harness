4. 一个诊断 Agent 与两个小型监督模块

模块一：基础监督预测语言、言语行为、辅助声学等专家分别产生折外概率；二层逻辑回归只用训练折学习专家组合，形成不依赖生成模型的基础风险。
Agent：证据审理读取 MetricEvidence、StateCard、任务轨迹和基础风险，选择可用证据、检查反证与混杂，并形成训练集原型支持度。测试标签不进入工作区。
模块二：有界风险修正用折外 Agent 变量训练小型修正模型。修正权限由证据覆盖率、可靠度和混杂负担共同控制；证据不足时严格退回基础概率。
校准与临床表达只用训练折选择修正强度并做温度校准。最终 Agent 将冻结概率与允许报告的证据写成医生可审查报告，不得改写数值结论。

5. 条件定义与 Agent 边界

B3 不是让大模型自由判断，也不是把监督概率换一种说法。Agent 参与证据选择、假设更新、反证检查和有界风险修正；两个小型监督模块负责从训练数据学习稳定组合与校准边界。最终文字报告是同一 Agent 的沟通阶段。

B1传统声学机器学习，不生成临床证据链。
B2直接诊断 Agent，只读原始转录并自行给出分类和报告。状态：{{ b2_status.status }}。
B3单一证据诊断 Agent + 基础监督模块 + 有界风险修正/校准模块。报告状态：{{ ours_report_status.status }}。
用途边界：研究性认知筛查与转诊支持，不替代神经心理量表、生物标志物或临床诊断。
所有病例结论必须能追溯到允许报告的 MetricEvidence、StateCard 与来源片段。
