1. 数据输入与切分

本轮只纳入 30–60 秒长音频。六秒切片被发现但明确排除；同一受试者的多条录音先分别提取，再聚合为一个建模单位，官方训练集与测试集之间执行受试者泄漏审计。官方将长语音定义为 60 秒图片描述任务，来源见 NCMMSC AD2021。

系统不根据录音序号继续猜测更细任务。NCMMSC 本地没有人工转录、内容单元答案表或说话人角色，因此 Ours 的中文语言状态和互动状态在本轮禁用，而不是用未经校验的代理数值补齐。

2. 一次运行如何完成

01 数据注册长音频清单、SHA-256、官方 split、受试者泄漏审计。
02 特征与片段从 WAV 重算声学指标，并从长音频内部生成 10 秒证据窗口。
03 MetricEvidence原值、HC 训练参考、方向、可靠度、缺失、混杂和报告权限。
04 StateCard同一临床构念内按医学权重 × 病例可靠度融合，保留反证和片段。
05 分层融合语音行为状态分支与低层声学辅助分支独立学习，再由可靠度门控。
06 评估与报告固定 B1/B2/Ours；生成医学 A 层、框架 B 层和两份 HTML。

缓存依据不是文件日期，而是输入文件、配置和代码的内容哈希。修改 metric 配置不会重跑音频解码；修改报告模板不会重训模型。每个 stage 的 executed/cached 状态写入 run manifest。

3. MetricEvidence：指标不是单个数

每个指标必须同时携带医学方向、技术可靠度、任务与设备混杂、缺失状态和报告权限。方向为 1 表示高于 HC 参考更异常，-1 表示低于参考更异常，0 表示没有足够医学依据指定单调方向，只能作模型辅助。

4. StateCard：状态内部融合

一个状态的分数不是简单平均。每条指标权重先乘病例级可靠度，缺失指标权重归零，再除以本病例有效权重总和。状态的 0 表示接近训练集 HC 中位参考；1–2 为边界偏离，≥2 为明显偏离；可靠度不足时直接标为 unreliable。

5. 状态外融合与训练

语音行为状态分支

S01–S03 进入标准化多项逻辑回归。它学习状态与 HC/MCI/AD 的关联，不重复学习未校准的一百多个低层特征。

低层声学辅助分支

MFCC、谱学、强度和基频只作辅助判别；病例权重被封顶为 {{ ours_meta.auxiliary_weight_cap }}，不进入疾病机制解释。

可靠度条件门控

架构允许分支可靠度影响 softmax 权重，再用训练集折外预测拟合多分类校准器。是否真的形成病例级动态权重，必须由训练结果审计，不能由架构名称直接推断。

6. Agent 在哪里，哪里不是 Agent

B1

不是 agent。它是可复现的传统声学 ML，不生成医生报告。

B2 direct agent

真实 {{ b2_status.model or 'agent' }} 只读取 Whisper ASR 转录，直接给分类和文字报告。状态：{{ b2_status.status }}。失败时不使用代理规则代替。

Ours

数值概率由可校准融合模型冻结；report agent 只把 MetricEvidence、StateCard 和片段证据翻译给医生，不能改概率。本轮报告 agent：{{ ours_report_status.status }}。

因此当前系统是 agent-assisted clinical system，而不是让 LLM 随机决定数值融合。这个边界保证同一输入、同一模型版本可以重建相同概率，并允许单独审计报告生成。
